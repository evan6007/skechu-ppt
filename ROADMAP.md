# Roadmap

## Near term

- Cross-browser regression fixtures for magnetic centerline routing.
- Better visual feedback for T-junction ownership and detach operations.
- Optional portable desktop package with signed Windows builds.
- Import and simplify existing SVG paths.
- Internationalized UI strings and an English default locale.

## Exploring

- macOS-friendly SVG/Keynote export without Office COM.
- Collaborative project format with deterministic diffs.
- Pluggable centerline detectors for noisy microscopy and scanned diagrams.

Roadmap items are directions, not commitments. Please open a discussion before implementing a large feature.
